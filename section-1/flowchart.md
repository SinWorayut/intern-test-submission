# Flowchart: Project Access Control

แผนภาพนี้ใช้ Mermaid ซึ่งแสดงผลได้ใน GitHub และตัวแสดง Markdown ที่รองรับ Mermaid

```mermaid
flowchart TD
    A([เริ่ม]) --> B[เปิดหน้า Login]
    B --> C[กรอก username และส่งคำขอเข้าสู่ระบบ]
    C --> D{ตรวจสอบผู้ใช้สำเร็จหรือไม่}
    D -- ไม่สำเร็จ --> E[แสดงข้อความ Login ไม่สำเร็จ]
    E --> B
    D -- สำเร็จ --> F{Role ของผู้ใช้}

    F -- Admin --> G[ไปหน้า /admin]
    F -- Employee --> H[ไปหน้า /employee]

    G --> I{Admin เปิด /employee หรือไม่}
    I -- ใช่ --> J[ปฏิเสธการเข้าถึง และ redirect ไป /admin พร้อมข้อความแจ้ง]
    J --> G
    I -- ไม่ใช่ --> K[แสดง Task ทั้งหมด และเครื่องมือจัดการสำหรับ Admin]
    K --> L[Admin สร้าง Project หรือ Task / มอบหมายงาน / เปลี่ยนสถานะได้]
    L --> M{Logout หรือไม่}
    M -- ไม่ --> K

    H --> N{Employee เปิด /admin หรือไม่}
    N -- ใช่ --> O[ปฏิเสธการเข้าถึง และ redirect ไป /employee พร้อมข้อความแจ้ง]
    O --> P[แสดงเฉพาะ Task ที่มอบหมายให้ Employee]
    N -- ไม่ใช่ --> P
    P --> X{Logout หรือไม่}
    X -- ใช่ --> V
    X -- ไม่ --> Q{เลือก Task ที่มอบหมายให้ตนเองหรือไม่}
    Q -- ไม่ --> R[ปฏิเสธการเปลี่ยนสถานะ และแจ้งว่าไม่มีสิทธิ์]
    R --> P
    Q -- ใช่ --> S{สถานะปัจจุบันเป็น To Do หรือไม่}
    S -- ไม่: เป็น Done แล้ว --> T[ปฏิเสธการย้อนสถานะเป็น To Do]
    T --> P
    S -- ใช่ --> U[อนุญาตเฉพาะการเปลี่ยน To Do เป็น Done]
    U --> P

    M -- ใช่ --> V[ล้างสถานะการ Login]
    V --> B
