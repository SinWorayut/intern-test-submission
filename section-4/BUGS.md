## จุดที่สงสัย

- `GET /api/tasks` กรอง Task ของ Employee ที่ server และหน้า Employee กรองซ้ำอีกชั้น แม้ซ้ำกันแต่เป็นการป้องกันข้อมูลรั่วและยังไม่ถือว่าเป็นบั๊ก
- `authenticate` ถูกถือว่าตอบ 401 เมื่อ token ไม่มีหรือไม่ถูกต้องตามเงื่อนไขในโจทย์ จึงไม่แก้ middleware
